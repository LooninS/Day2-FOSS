# FOSS Day 2: Git & GitHub Workshop (2026)

Repo for the Day 2 session of the FOSS workshop. Today is about using Git the way it's used on actual projects: working with branches, going back to older commits, and fixing things when you break them.

## Getting Started

Clone the repo and set up your Git:

```bash
git clone https://github.com/LooninS/Day2-FOSS.git
cd Day2-FOSS

git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
```

## Contributing

1. Fork the repo
2. Create a branch for your work
3. Commit and push your changes
4. Open a Pull Request

Happy hacking! 🎉
